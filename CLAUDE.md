# Persona — project guide

Personal companion PWA. Ekdom vanilla: **no build step, no framework, no
backend**. Browser e `index.html` khullei cholbe. Sob data phone-er
`localStorage` e thake — kono server e kichu jay na.

## Stack
- Plain HTML + CSS + ES2020 JavaScript (no modules/bundler — scripts globally load hoy)
- Service worker (`sw.js`) — offline cache
- `manifest.json` — installable PWA (standalone, portrait)
- Fonts `fonts/` e self-hosted, icons `icons/` e (generated by `gen_icons.py`)

## Run
```bash
python3 -m http.server 8000   # tarpor http://localhost:8000
```
`file://` diye service worker + notification kaj korbe na — always serve over
http/https. Tests/linter ei repo te nei; change korle browser e nijei check koro.

## Files
| File | Ki ache |
|---|---|
| `index.html` | Sob view er markup + sheet/modal, script tag gulo (order matters: app → chat → alarm) |
| `app.js` | Storage layer (`DB`), state, sob view render, nav, notification, task due-check |
| `chat.js` | Chat brain — Banglish NLU parser, action registry, optional Gemini LLM mode |
| `alarm.js` | Alarm tone synth (WebAudio), ringing/snooze/dismiss, alarm scheduling |
| `styles.css` | Sob style (single file, CSS variables theme) |
| `sw.js` | Cache-first service worker |
| `gen_icons.py` | Icon generator (Pillow) — icons already committed, rarely rerun |

## Architecture notes
- **Globals are the API.** `app.js` er `tasks`, `addTask()`, `save.*`,
  `render()`, `DB` — egulo global, `chat.js` ar `alarm.js` egulo direct use kore.
  Notun file add korle script order thik rakhte hobe.
- **Storage keys** `shathi.*` prefix use kore (project er purono naam) —
  rename korle purono user er data hariye jabe, so oita rekhe deya hoyeche.
- **Views**: `render(view)` ekta switch — notun view add korle
  `TITLES`/`EYEBROWS` map ar nav button duitatei entry lagbe.
- **Escaping**: HTML string diye render hoy, tai user text always `esc()`
  diye pass korte hobe — XSS er ekmatro protection oitai.

## Chat brain (chat.js)
Duita mode:
1. **Offline brain** (default) — `parseIntent()` rule + fuzzy match diye
   intent ber kore, `ACTIONS` registry theke run kore. Kono key lage na.
2. **LLM mode** (optional) — user nijer Gemini API key settings e dile
   `askLLM()` chole. LLM shudhu *kon action* ta thik kore; action gulo
   ekhankar registry theke-i chalay, tai LLM arbitrary kichu korte pare na.

Notun capability add korle: `ACTIONS` e ekta entry, `LLM_TOOLS` string e tar
description, ar offline `parseIntent()` e keyword — tinta jaygatei lagbe.

## Security
- **API key user er nijer**, `localStorage` e thake, shudhu Google er
  endpoint e jay. Repo te kono key nei ebong kokhono commit korbe na.
- `.claude/settings.local.json` local-only, gitignored.
